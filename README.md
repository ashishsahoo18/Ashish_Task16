# Student Cards with Live Search

Displays student records as cards and filters them by name as the user types.

## Features
- Array of student objects (name, marks, class, address)
- Cards generated dynamically with `Array.map()`
- Real-time search by name with `Array.filter()` (case-insensitive)
- "No students found." message when nothing matches

## Files
- `index.html` – page structure
- `style.css` – card and layout styling
- `script.js` – data, rendering and search logic
- `Readme.md` – this file

## How to run
Open `index.html` in a browser and type in the search box.
